Filter format reference (BinMaster-compatible) 
A flip must clear the four global gates, must NOT hit a matching Blacklist tier,
and must match >=1 Consider tier (its matcher matches AND every set min_* holds).
The highest-priority matching Consider tier's scale_price sets the listing price.

Item keys: item id (HYPERION, MIDAS_SWORD), pets as PET_<TYPE>, or GLOBAL (all items).
Consider fields are all optional — a blank field is simply not gated.
"max sell" is shown in HOURS here; stored as ms (86.4M / volume-per-day estimate).
matcher {} matches everything; fields resolve to enchant levels, kuudra attributes,
stars, gem_slots, recombobulated (0/1). e.g. {"double_hook":{"Number":{"Equal":[1]}}}.
Anything the form does not model (exotic matchers, extra keys) is preserved on save;
use Raw JSON mode for those.
